1- Para restaurar o Windows 11 faça o seguinte:

  1. Abra o menu de configurações de sistema

Use o comando tecla “Windows+i” ou faça o caminho; Menu Iniciar >

Configurações > Sistema;

  1. Encontre a aba Recuperação

Após abrir o menu de configurações do sistema, selecione o campo “Recuperação”;

Restaure o computador

Clique no campo “Restauração” e depois selecione “Restaurar o computador”

  1. Defina se pretende manter ou excluir arquivos

No campo seguinte há duas opções que envolvem manter ou apagar arquivos. Escolha “Remover tudo”, caso pretenda apagar todos os arquivos do PC ou “Manter meus arquivos” para excluir programas, porém manter seus arquivos pessoais;

 

  1. Defina como reinstalar o Windows 11

Na tela seguinte, você pode definir se pretende reinstalar o Windows 11 a partir da nuvem ou instalar localmente por um dispositivo.

 2- Como restaurar o Windows 10 e apagar arquivos

Caso a proteção do sistema não esteja ativada, será preciso restaurar o computador. Esta ação reverte todos os programas e drivers instalados para a versão original do Windows, mas pode manter ou não seus arquivos pessoais dependendo das configurações selecionadas.

  1. Procure por Configurações;
  2. Clique em Atualização e Segurança;
  3. Clique em Recuperação;
  4. Clique em Começar e escolha se deseja restaurar o sistema mantendo os arquivos ou removendo tudo.

3 - Como restaurar o Windows 10

Para restaurar o Windows 10 utilizando um ponto de restauração e igual ao processo no Windows7:

  1. Acesse o Painel de Controle;
  2. Procure por Restauração;
  3. Selecione Recuperação , depois Abrir Restauração de Sistema e, por último, Avançar;
  4. Escolha o ponto de restauração relacionado ao aplicativo ou driver com problema e selecione Avançar e depois Concluir.

4 -Como restaurar o Windows 7

No Windows 7:

  1. Acesse o Painel de Controle;

  1. Acesse-> Sistemas e Segurança, depois Central de ação -> Restaurar um estado anterior do Computador;

  1. Clique em Abrir Restauração do Sistema;

  1. Na nova janela, clique em Avançar;

  1. Aqui você pode selecione o ponto que deseja restaurar de acordo com a data, procurar programas afetados outro tros pontos ou avançar com ponto selecionado

  1. Confirme o ponto selecionado e clique em concluir o processo de restauração leva alguns minutos; portanto, não desligue o computador até que ele seja concluído.

Caso não tenha resolvido ou o ponto de restauração escolhido não seja o correto, é

possível reverter as alterações.

Execute novamente os passos e, na tela de seleção do ponto de restauração, escolha o ponto do tipo “Desfazer”.

Também é possível acessar o programa de restauração do sistema pelo prompt de comando.

No Windows, aperte a tecla Windows + R, digite cmd e aperte Enter. Depois, execute o comando rstrui.

5 - Criar pendrive de instalação do windows

5.1. O que você vai precisar

Computador

Com conexão à internet estável (o download tem vários GB)

Pendrive

Vazio, com pelo menos 8 GB de espaço livre

Tempo

O processo pode levar de 20 minutos a algumas horas, dependendo da internet

Chave do produto

Opcional — não é necessária se o Windows já é ativado digitalmente no computador

5.2. Baixando a Ferramenta de Criação de Mídia

A Microsoft disponibiliza uma ferramenta diferente para cada versão do Windows. Escolha o site de acordo com a versão que deseja instalar.

Windows 10

Acesse o site oficial de download do Windows 10 e, na seção "Criar mídia de instalação do Windows 10", clique em "Baixar Agora”.

Endereço para baixa Windows 10  https://www.microsoft.com/pt-br/software-download/windows10ISO

Endereço para baixa Windows 11 https://www.microsoft.com/pt-br/software-download/windows11

Site oficial de download do Windows 10

Botão "Baixar Agora" na seção de criação de mídia

Windows 11

Acesse o site oficial de download do Windows 11 e, na seção "Assistente de Instalação do Windows 11", clique em Baixe agora.

Site oficial de download do Windows 11

DICA

O suporte ao Windows 10 terminou em 14/10/2025. Sempre que possível, prefira instalar o Windows 11 em computadores compatíveis.

5.3. Executando o Assistente de Instalação

Depois de baixado, o arquivo MediaCreationTool.exe fica disponível na pasta Downloads. Os passos a seguir são os mesmos para Windows 10 e Windows 11.

  1     Localize o instalador

Abra a pasta Downloads e dê um clique duplo (ou clique) no arquivo MediaCreationTool.exe.

Arquivo Media Creation Tool.exe na pasta Downloads

  2     Execute como administrador

Clique com o botão direito do mouse sobre o arquivo e selecione "Executar como administrador". Isso é necessário para que a ferramenta tenha permissão de criar a mídia.

Menu de contexto — opção "Executar como administrador"

  3     Aceite os termos de licença

Leia e clique em Aceitar para continuar.

Tela de termos de licença do Windows

  4     Escolha "Criar mídia de instalação"

Na pergunta "O que você deseja fazer?", selecione a opção Criar mídia de instalação (pen drive, DVD ou arquivo ISO) para outro computador e clique em Avançar.

Seleção da opção de criar mídia de instalação

  5     Selecione idioma, edição e arquitetura

Escolha o Idioma, a Edição do Windows e a Arquitetura (32 bits, 64 bits ou Ambas). Se não tiver certeza, marque a caixa Usar as opções recomendadas para este computador — ela preenche tudo automaticamente com base no computador atual.

             

Tela de seleção de idioma, edição e arquitetura - Escolha da arquitetura: 32 bits, 64 bits ou Ambas

Opção marcada "Usar as opções recomendadas para este computador" - Escolha entre Unidade flash USB ou Arquivo ISO

  6     Escolha o tipo de mídia

Escolha entre:

  1. Unidade flash USB — cria o instalador direto no pendrive (mínimo 8 GB).
  2. Arquivo ISO — cria um arquivo que depois pode ser gravado em um DVD ou usado em uma máquina virtual.

  7     Selecione o pendrive

Conecte o pendrive antes deste passo. Clique em Atualizar a lista de unidades se ele não aparecer, selecione-o na lista e clique em Avançar.

Seleção da unidade flash USB conectada

  8     Aguarde o download e a criação

A ferramenta faz alguns preparativos e depois baixa os arquivos do Windows diretamente da Microsoft. Não desconecte o pendrive nem feche a janela durante esse processo.

 

Tela "Fazendo alguns preparativos" - Tela "Baixando Windows" com barra de progresso

  9     Conclua o processo

Quando aparecer a mensagem "Sua unidade flash USB está pronta", clique em Concluir. O pendrive já pode ser usado para instalar o Windows em qualquer computador compatível.

Mensagem de conclusão — pendrive pronto para uso

5.4. Se der erro: como formatar o pendrive

Às vezes a ferramenta apresenta erro ao tentar gravar no pendrive, principalmente se ele já tiver sido usado para outra instalação ou tiver um sistema de arquivos incompatível. Nesse caso, formate o pendrive e repita o processo a partir do Passo 6.

  1     Abra o menu do pendrive

No Explorador de Arquivos, clique com o botão direito sobre o ícone do pendrive.

Menu de contexto do pendrive

  2     Selecione Formatar

Clique na opção Formatar... no menu que aparece.

Opção "Formatar..." no menu de contexto

  3     Configure e inicie a formatação

Em Sistema de arquivos, escolha FAT32 (Padrão), mantenha a Formatação Rápida marcada e clique em Iniciar.

Janela de formatação — sistema de arquivos FAT32

ATENÇÃO

A formatação apaga todo o conteúdo do pendrive imediatamente e não pode ser desfeita.
