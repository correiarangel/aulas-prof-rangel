  Objetivo do Projeto

Criar um sistema completo de controle de vendas que demonstre todas as habilidades aprendidas durante o curso: formatação, fórmulas, validação de dados, tabelas dinâmicas e macros.

  Briefing do Projeto

Cenário

A empresa Tech Solutions tem um problema com o controle de volume de vendas e desempenho de vendedores, imagine que você foi contratado para criar um sistema de controle de vendas da empresa fictícia.

O sistema deve permitir:

  • Cadastro de vendas mensais. Pense como posso resolver isso ?
  • Análise automática de performance. Qual a ferramenta pode gerar um relatório automático ?
  • Relatórios visuais com gráficos Como vou gerar gráficos no excel  ? Inserir -> Gráficos -> selecione o tipo de gráfico Horizontal por exemplo .
  • Dashboard executivo. O que é um Dashboard ou Painel de controle ? O nome já responde a pergunta painel de controle e um local onde concentra varia ferramentas atalho para ferramentas análises literalmente um lugar onde algo pode ser controlado de forma centralizada

 Etapa 7 – Automatização com Macros

  7.1 Macro 1 – Atualizar Dados

Esta macro atualiza a tabela dinâmica Analise_Vendedor e navega para elai.

Como gravar:

  1. Aba Desenvolvedor → Gravar Macro → Insira o Nome: AtualizarDados → OK
  2. Vá para plan →  Analise_Vendedor → clique com botão direito na tabela dinâmica → Aba dados → Atualizar Tudo
  3. Agora clica na plan → Dashboard
  4. Na Aba Desenvolvedor → Parar Gravação
  5. Aba Desenvolvedor → grupo Controles → Inserir → Botão do tipo (Controle de Formulário) desenhe um retângulo, na janela que abre selecione o macro gravado  → AtualizarDados, 
  6. Seleciona o botão recém criado clique com botão direito do mouse sobre o botão → Editar texto rótulo do botão → Digite:  Atualizar Dados→ clica em → exibir código ou Visual Basic vocẽ verá o código gerado com a gravação da macro.
  7. Digite na penúltima linha da função o código abaixo onde MsgBox é uma função nativa do vba que cria caixas de mensagens para nós e vbInformation e o tipo da mensagem no caso informativo.

     digite: MsgBox "Dados atualizados com sucesso!",vbInformation

Código gerado (Visual Basic):

1 Sub AtualizarDados()

2

3    Sheets("Analise_Vendedor").Select

4    ActiveSheet.PivotTables(1).RefreshTable

5    Sheets("Dashboard").Select

6    MsgBox "Dados atualizados com sucesso!", vbInformation

7

8 End Sub

Agora teste quando clicar no botão deverá mostrar a mensagem "Dados atualizados com sucesso!" e navega para análise de vendas
