Aula 8: Diagnóstico de Memória, Restauração do Sistema e Criando Mídia de Instalação no Windows

Guia Prático "Mão na Massa": Execute cada passo diretamente no seu computador e marque as caixas de confirmação para acompanhar seu progresso!

📌 Atividade Complementar desta Aula

1. Diagnóstico de Memória RAM do Windows (Teste de Memória)

A memória RAM é responsável pela velocidade e execução dos programas no computador. Se a máquina está travando com frequência ou apresentando telas azuis inesperadas, é essencial testar os pentes de memória física em busca de defeitos.

🖐️ Passo a Passo Prático no Seu Computador

  1. Pressione a combinação de teclas Win + S no teclado para abrir a barra de pesquisa do Windows.
  2. Digite exatamente: "Diagnóstico de Memória do Windows".
  3. Clique no aplicativo localizado para abrir a caixa de ferramentas.
  4. Escolha a opção: "Reiniciar agora e verificar problemas".

⚠️ Atenção em sala de aula: Aguarde a autorização prévia do professor Marcos Rangel antes de reiniciar o computador do laboratório!

Janela nativa do Diagnóstico de Memória do Windows com opção de reinicialização.

Após o reinício, o Windows iniciará uma varredura profunda na memória física antes de carregar a Área de Trabalho. Quando o teste terminar, o sistema iniciará normalmente e exibirá um relatório na barra de notificações confirmando se a memória está saudável ou se necessita de substituição.

📖 Certifico que entendi como localizar e executar o Diagnóstico de Memória RAM nativo do Windows.

2. Como Restaurar o Windows 11 e Windows 10 (Restauração Padrão)

A restauração do sistema é a solução ideal quando o sistema operacional apresenta lentidão severa, vírus de difícil remoção ou erros de arquivos corrompidos. O processo de recuperação padrão é extremamente parecido no Windows 10 e no Windows 11, mudando apenas a disposição visual dos menus.

🖐️ Passo a Passo Prático no Windows 11

  1. Abra o menu de Configurações: Pressione a combinação de teclas Win + I ou acesse o Menu Iniciar > Configurações > Sistema.
  2. Acesse a opção Recuperação: Role a lista até o campo "Recuperação".
  3. Clique em Restaurar o Computador: Na opção "Restaurar o PC", clique no botão azul "Restaurar o computador".

Acessando o menu de Configurações > Sistema > Recuperação no Windows 11.

Painel de Recuperação no Windows 11 destacando a opção "Restaurar o computador".

🖐️ Passo a Passo Prático no Windows 10

  1. Abra as Configurações: Pressione Win + I ou acesse Menu Iniciar > Configurações.
  2. Acesse Atualização e Segurança: Clique na opção "Atualização e Segurança".
  3. Selecione Recuperação: Clique na aba Recuperação à esquerda e, no campo "Restaurar o PC", clique no botão "Começar".

Menu de recuperação do Windows 10 — O processo de restauração é equivalente ao do Windows 11.

Definindo a Opção de Arquivos (Manter vs Remover)

Tanto no Windows 10 quanto no Windows 11, ao iniciar a restauração, o assistente perguntará qual estratégia você deseja seguir:

Janela de escolha entre "Manter meus arquivos" e "Remover tudo".

  • "Manter meus arquivos" (Recomendado): Remove todos os programas instalados e restaura as configurações do sistema, mas PRESERVA todos os seus documentos, fotos, PDFs e arquivos pessoais.
  • "Remover tudo": Apaga completamente todos os arquivos, documentos, contas de usuário e programas, deixando o computador como novo de fábrica.

Em seguida, você pode escolher se prefere reinstalar o Windows através de Download da Nuvem (baixa os arquivos atualizados diretamente da Microsoft) ou Reinstalação Local (utiliza a imagem gravada no próprio disco).

📖 Certifico que compreendi o processo de restauração padrão no Windows 11 e Windows 10 (Manter vs Remover).

3. Restauração por Ponto de Restauração (Painel de Controle e Comando rstrui)

Além da restauração padrão que reinstala o sistema, o Windows conta com o recurso de Ponto de Restauração. Esse recurso salva o "estado" do computador em datas específicas. Se a máquina apresentar um problema após instalar um programa ou atualização, você pode voltar o relógio do sistema para uma data anterior em que tudo funcionava perfeitamente, sem afetar seus documentos recentes.

3.1 Acessando via Painel de Controle (Windows 7 / 10 / 11)

🖐️ Passo a Passo Prático no Painel de Controle

  1. Acesse o Painel de Controle no menu de busca do Windows.
  2. Acesse Sistema e Segurança > Central de Ações (ou Recuperação).
  3. Clique no link "Restaurar um estado anterior do computador" e selecione "Abrir Restauração de Sistema".

Acessando a seção Sistema e Segurança no Painel de Controle.

Opção "Restaurar um estado anterior do computador" na Central de Ações / Recuperação.

3.2 O Assistente de Restauração do Sistema

Ao abrir o assistente, clique em Avançar para visualizar a lista de pontos de restauração salvos automaticamente pelo sistema ou criados antes de atualizações:

Tela inicial do assistente nativo de Restauração do Sistema.

Avançando para a tela de seleção de datas.

Escolha o ponto de restauração com base na data e hora em que o computador funcionava corretamente.

⚡ Comando Rápido no Teclado (Dica do Professor Marcos Rangel):
Você pode abrir diretamente o assistente de Restauração do Sistema em qualquer versão do Windows sem navegar pelos menus:
1. Pressione Win + R para abrir a janela Executar (ou abra o Prompt de Comando cmd).
2. Digite exatamente rstrui e pressione Enter!

Reversão ("Desfazer"): Caso o ponto de restauração escolhido não resolva o problema ou piore a situação, você pode desfazer a alteração! Abra o assistente novamente e selecione o ponto do tipo "Desfazer".

📖 Certifico que entendi como utilizar os Pontos de Restauração e o comando rápido rstrui.

4. Criando Pendrive de Instalação do Windows (10 e 11)

Criar um Pendrive de Instalação (mídia de boot) permite formatar e instalar o Windows em qualquer computador, mesmo que a máquina antiga não consiga mais ligar.

4.1 O que você vai precisar:

Item Necessário Especificação Recomendada
🖥️ Computador Com conexão à internet estável (download de 4GB a 6GB).
💾 Pendrive Vazio, com no mínimo 8 GB de espaço livre.
⏱️ Tempo De 20 minutos a 1 hora (depende da velocidade da internet).
🔑 Chave do Produto Opcional — Não necessária se o PC tiver licença digital.

4.2 Baixando a Ferramenta Oficial (Media Creation Tool)

Acesse o site oficial da Microsoft de acordo com a versão desejada:

🌐 Windows 10: microsoft.com/pt-br/software-download/windows10ISO
🌐 Windows 11: microsoft.com/pt-br/software-download/windows11

Página oficial da Microsoft para download do Windows 10.

Clique no botão "Baixar Agora" na seção "Criar mídia de instalação do Windows 10".

Página oficial da Microsoft para download do Assistente do Windows 11.

4.3 Executando o Assistente Passo a Passo

🖐️ Passo a Passo da Criação da Mídia USB

  1. Localize o instalador: Abra a pasta Downloads e encontre o arquivo MediaCreationTool.exe.
  2. Executar como administrador: Clique com o botão direito do mouse no arquivo e selecione "Executar como administrador".
  3. Termos de licença: Clique no botão "Aceitar".
  4. O que você deseja fazer?: Marque a opção "Criar mídia de instalação (pen drive, DVD ou arquivo ISO)" e avance.
  5. Idioma e Arquitetura: Escolha o idioma (Português Brasil) e a Arquitetura (64 bits ou 32 bits). Ou mantenha a caixa "Usar as opções recomendadas" marcada.
  6. Tipo de Mídia: Selecione a opção "Unidade flash USB".
  7. Selecione o Pendrive: Conecte o pendrive na entrada USB do PC, selecione-o na lista e clique em Avançar.
  8. Aguarde o Download e Criação: O assistente baixará os arquivos e criará o pendrive inicializável automaticamente.

5. Se der Erro: Como Formatar o Pendrive em FAT32

Em alguns casos, a ferramenta da Microsoft pode apresentar mensagem de erro ao tentar gravar no pendrive (caso a unidade contenha partições antigas ou sistema de arquivos incompatível). Para resolver, basta formatar o pendrive previamente!

🖐️ Passo a Passo da Formatação no Explorador de Arquivos

  1. Pressione Win + E para abrir o Explorador de Arquivos.
  2. Localize o ícone do Pendrive em "Este Computador".
  3. Clique com o botão direito do mouse sobre o pendrive.
  4. Clique na opção "Formatar...".
  5. No campo Sistema de arquivos, selecione FAT32 (Padrão).
  6. Mantenha a opção "Formatação Rápida" marcada e clique em Iniciar.

Menu de contexto acessado com o botão direito sobre a unidade USB.

Selecionando a opção "Formatar...".

Janela de formatação ajustada para o padrão FAT32.

⚠️ ALERTA DE SEGURANÇA (PERDA DE DADOS):
A formatação APAGA todos os arquivos e dados salvos no pendrive de forma imediata e irreversível! Certifique-se de não possuir documentos pessoais gravados na unidade antes de clicar em Iniciar.

1. A História dos Computadores

Os computadores não surgiram prontos como os conhecemos hoje. Eles nasceram de uma necessidade muito séria: durante a Segunda Guerra Mundial (1939–1945), era preciso resolver cálculos complexos rapidamente — e foi aí que tudo começou.

Imagem 01/07 — Programadoras operam o primeiro computador eletrônico da história, o ENIAC • Foto: ARL Technical Library / U.S. Army.

O ENIAC: fevereiro de 1946

O ENIAC foi apresentado em fevereiro de 1946 e é considerado o primeiro computador eletrônico da história. Ele ocupava uma sala inteira e pesava toneladas. O detalhe mais surpreendente: ele não tinha programa — as programadoras (mulheres que reconfiguravam a máquina na mão, conectando cabos e botões) eram responsáveis por dizer ao computador o que ele deveria fazer.

Imagem 02/07 — Alan Turing e a máquina Enigma, usada pelos alemães na Segunda Guerra Mundial para codificar mensagens.

Nessa mesma época, o matemático britânico Alan Turing criou uma máquina capaz de "quebrar" os códigos do exercíito — o trabalho dele é a base de tudo o que chamamos hoje de computação.

💡 Para ver: o filme O Jogo da Imitação conta essa mesma época e mostra por que o trabalho de Turing foi tão importante.
📋 Resumo do Tópico 1

1939–1945 — Guerra: surgem os primeiros computadores • 1946 — ENIAC, o primeiro computador eletrônico, operado por programadoras • Turing — cria a base do cálculo automático.

3. Como o Computador "Pensa": o Código Binário

Por mais avançado que pareça, um computador é, no fundo, uma grande calculadora. Toda a informação que ele processa — textos, fotos, vídeos, sons — é transformada em apenas dois estados possíveis:

Código Binário — a única linguagem da máquina
Estado Código O que acontece na máquina
Ligado 1 Corrente elétrica passa → o circuito está "ligado".
Desligado 0 Não passa corrente → o circuito está "desligado".

É essa combinação de zeros e uns que forma o código binário, a linguagem que todo computador entende por trás das telas. Um ícone, uma música, uma foto — tudo acaba virar uma enorme lista de 0 e 1 antes de aparecer na tela.

⚠️ Atenção: 1 bit é um único dígito binário (0 ou 1). 8 bits formam 1 byte — e um byte só representa um caractere. É assim que um arquivo de 1 MB (1.048.576 bytes) ainda cabia em um disquete de 1,44 MB.
📋 Resumo do Tópico 3

Computador = grande calculadora • 2 estados: 1 (ligado) e 0 (desligado) • 8 bits = 1 byte = 1 caractere.

📖 Certifico que entendi o que é código binário e por que o computador só entende 0 e 1.

4. O Caminho da Informação: Entrada → Processamento → Saída

Todo processamento de dados segue um caminho simples, dividido em três etapas:

Etapa O que acontece
Entrada O que o computador recebe do usuário — teclado, mouse, microfone, câmera, entre outros.
Processamento O que o computador faz com a informação recebida, usando o processador (CPU) para calcular e tomar decisões.
Saída O resultado que aparece para o usuário — monitor, som, impressora, entre outros.

Imagem 04/07 — teclado/mouse (Entrada) → um ícone de processador (Processamento) → um monitor (Saída).

💡 Pense assim: é exatamente o mesmo caminho do seu dedo no teclado até a letra aparecer na tela. Sem entrada, não há processamento; sem processamento, não há saída.
📋 Resumo do Tópico 4

Entrada (teclado, mouse, microfone, câmera) → Processamento (CPU calcula e decide) → Saída (monitor, som, impressora).

📖 Certifico que consigo explicar as três etapas: entrada, processamento e saída.

6. O Sistema Operacional: o "Gerente" do Computador

O sistema operacional é o programa responsável por gerenciar o hardware e os outros programas do computador. É ele que permite que você interaja com a máquina através de telas, ícones e menus — sem ele, o computador seria apenas "uma tela preta".

Ano Marco do sistema operacional
1971 Unix — surgem os primeiros sistemas operacionais.
1981 IBM PC — traz o conceito de computador pessoal.
1985 Windows 1.0 — sistema operacional gráfico da Microsoft.
1991 Linux — criado por Linus Torvalds, gratuito e aberto.
2007 iOS — lançado pela Apple junto com o iPhone.
2008 Android — sistema operacional do Google para dispositivos móveis.

Imagem 07/07 — Logotipos do Unix, IBM PC, Windows, Linux, iOS e Android.

Os principais tipos de sistema operacional hoje

Sistema Onde ele é usado
Windows O mais popular em computadores pessoais no mundo todo.
Linux Livre e gratuito, muito usado em servidores e por programadores.
macOS Sistema exclusivo para computadores da Apple.
Android / iOS Sistemas operacionais voltados para celulares e tablets.

Curiosidade da aula: e o Linux, como é?

O Linux apareceu na tabela acima como um sistema livre, gratuito e aberto. Muita gente usa Linux todos os dias — e a maioria nunca percebeu. Se quiser entender o que ele é, como funciona por dentro e por que ele costuma ser uma escolha tão boa, abra a aba extra abaixo. Não entra na prova: é só conhecimento.

FASE 0 — Preparação Teórica e Prática

🎯 Objetivo desta aula

Entender os recursos de segurança nativos do Windows: usar a Central de Segurança/Ações, manter o antivírus e o firewall ativos, conferir as atualizações, criar backups e pontos de restauração, e reconhecer os riscos da pirataria de programas e jogos. Compatível com Windows 7 / 10 / 11.

🗺️ Roteiro Numerado (Passo a Passo)

  1. Abrir a Central de Segurança (Central de Ações no Windows 7) e ver o estado geral de proteção.
  2. Verificar se o antivírus do Windows está ativado.
  3. Fazer uma verificação rápida de vírus.
  4. Conferir as atualizações de segurança no Windows Update.
  5. Abrir o Firewall e confirmar que está ativado nas três redes.

7. Os Riscos da Pirataria

Usar programas e jogos piratas (crackeados) é perigoso e pode colocar todo o computador em risco. Veja os principais motivos para evitá-los:

1. O que é um arquivo .BAT?

Um arquivo .bat ("batch", em inglês) é um arquivo de texto simples que guarda uma lista de comandos do Prompt de Comando do Windows. Quando o aluno dá dois cliques nesse arquivo, o Windows executa os comandos um a um, automaticamente — sem precisar digitar nada na hora.

Na prática, o .bat funciona como uma "receita": você escreve o passo a passo uma única vez, salva, e depois basta clicar para repetir a tarefa sempre que quiser.

O arquivo .bat guarda comandos que o Prompt de Comando executa automaticamente.

💡 Por que usar .bat para backup?
Porque transforma uma tarefa repetitiva (copiar arquivos manualmente) em um processo de um clique só — reduzindo erros e economizando tempo.

3. Script de Backup para Pendrive

Agora que você já sabe criar e executar um .bat, vamos montar um script que copia arquivos de uma pasta do computador para um pendrive — o backup automático.

Como funciona

O script usa o comando xcopy, que copia pastas inteiras (incluindo subpastas). O aluno só precisa ajustar duas informações no início do arquivo:

  • ORIGEM — o caminho da pasta que ele quer copiar (backup).
  • DESTINO — a letra do pendrive, seguida da pasta onde os arquivos serão salvos.

O comando xcopy copia os arquivos da pasta de origem para o pendrive.

Como descobrir a letra do pendrive antes de montar o script (no Explorador de Arquivos, "Este Computador").

🖐️ Passo a Passo

  1. Conecte o pendrive e anote a letra da unidade.
  2. Abra o Bloco de Notas e digite o script abaixo:
@echo off
REM ==== Aluno: ajuste as duas linhas abaixo ====
set ORIGEM="C:\Usuarios\SeuNome\Documentos"
set DESTINO=E:\Backup
echo Iniciando backup...
xcopy %ORIGEM% %DESTINO% /E /I /Y
echo Backup concluido!
pause
  1. Troque o caminho depois de ORIGEM= pelo caminho real da pasta que deseja copiar.
  2. Troque a letra E: depois de DESTINO= pela letra do pendrive do seu computador.
  3. Salve como backup.bat (Tipo: "Todos os arquivos").

Script de backup no Bloco de Notas — as linhas em vermelho são as que o aluno ajusta (ORIGEM e DESTINO).

📖 Certifico que montei o script backup.bat e ajustei as linhas ORIGEM e DESTINO com as minhas informações.

4. Executando e Conferindo o Backup

Com tudo configurado, é hora de executar o backup e conferir se os arquivos chegaram ao pendrive.

🖐️ Passo a Passo da Execução

  1. Com o pendrive conectado, dê dois cliques em backup.bat.
  2. Aguarde a mensagem "Backup concluido!" na tela.

O Prompt de Comando mostra cada arquivo copiado e confirma o fim do backup.

💡 O que significa /E /I /Y?
/E copia também as subpastas (mesmo vazias); /I trata o destino como pasta (evita erro de confirmação); /Y substitui arquivos existentes sem perguntar a cada um.

🐧 Saiba Mais: o Linux

GNU/Linux é uma família de sistemas operacionais livres. Ele é formado por três coisas que trabalham juntas:

🧠 O kernel Linux — o "cérebro"

O kernel é o núcleo que conversa direto com o hardware: ele administra a memória, os programas em execução, os dispositivos (teclado, mouse, impressora, disco) e as permissões dos arquivos. Só com o kernel não se chega a um computador usável.

🛠️ O projeto GNU — as ferramentas básicas

Sã o conjunto de comandos e programas que você usa no terminal e em segundo plano. O nome vem de GNU's Not Unix — "GNU não é Unix".

📦 A distribuição — o "kit completo"

Junta o kernel, as ferramentas, os aplicativos, o instalador e o gerenciador de pacotes. É a distribuição: Ubuntu, Debian, Linux Mint, Fedora, openSUSE. Todas usam o mesmo kernel — o que muda é o "kit" e a interface.

Software livre significa poder usar, estudar, modificar e compartilhar. Ninguém precisa pagar licença para instalar o sistema, e o código é público para qualquer pessoa conferir se há algo escondido.

A diferença que você sente na prática

No Windows, para instalar um programa você quase sempre baixa um arquivo .exe de um site e clica duas vezes — um clique errado e o sistema pede permissão de administrador. No Linux, os programas têm um catálogo oficial (o repositório), e a instalação é feita por um comando ou por um ícone único, com segurança e checagem.

📚 Repositório e gerenciador de pacotes

O gerenciador de pacotes instala, atualiza e remove programas a partir dos repositórios oficiais da distribuição. É o equivalente a uma "loja confiável" já instalada no sistema — por isso muitos usuários nem instalam nada de fora, e o computador fica mais seguro.

🔑 Usuários e permissões: a proteção vem por desenho

Cada pessoa tem um usuário próprio, e só o administrador mexe no sistema. Se você abrir um arquivo estranho, ele não consegue alterar o sistema inteiro — a proteção existe antes do antivírus agir.

🖼️ A interface é uma escolha, não um imposição

Ambientes como GNOME, KDE Plasma e XFCE mudam a aparência e o comportamento do ambiente gráfico sem trocar o sistema inteiro. Trocar de interface é como trocar de tema.

⌨️ O terminal

É o lugar onde o Linux mostra sua verdadeira potência. Comandos como ls (listar), cd (entrar numa pasta), cp (copiar) e sudo (executar como administrador) resolvem em segundos tarefas que no Windows exigem vários cliques.

Teste antes de trocar: rode uma distribuição em máquina virtual, pendrive live ou computador secundário. Assim você conhece o sistema sem arriscar o seu dia a dia.

Não é que o Linux seja "milagroso". Ele resolve problemas de um jeito diferente — e, em várias situações do dia a dia, resolve melhor e mais barato:

Aspecto No Windows No Linux
Licença Paga (ou atualizações recorrentes em versões novas). Gratuito e de código aberto.
Instalação de programas Baixar .exe de sites variados. Repositório oficial, com checagem de integridade.
Segurança básica O usuário é administrador; permissõo ampla por padrão. Usuário comum x administrador, separado por padrão.
Velocidade Engorda com o tempo; exige hardware mais novo. Roda bem até em máquinas antigas (com uma distro leve).
Estabilidade Reinícios e atualizações frequentes. Servidores ficam dias ou semanas no ar.
Controle da máquina Coleta de dados e serviços de fundo comuns. Tudo desligável; código público para auditar.
Interface Um visual único, acoplado ao sistema. GNOME, KDE, XFCE… trocáveis livremente.
Resumo honesto: o Linux não serve para tudo e para todo mundo. Quem depende de programas muito específicos (ou de jogos com proteção anticopia) pode encontrar limitações. Mas para navegar, estudar, trabalhar com documentos, usar a internet e manter o computador seguro e leve, ele é uma ótima escolha.
